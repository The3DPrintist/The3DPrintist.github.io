Hello World!

During the development of Diora, I wanted a devlog that I could use to make updates and document specific Diora-related systems like the rendering engine, art, and design. Unfortunately, of my websites are (currently) made vanilla, (without a framework), and are static (no backend), since its hosted with GitHub Pages. I needed a system that would work with just javascript.

I was inspired by Rae's blog posts (on rae.wtf) to duplicate that system and put it here as well!

It is pretty bare bones but is very easy to manage, and quite capable. The entire system works around a div being filled with the contents of a .html file, which is hosted in the same folder. The only downside is that uploading or edits require a push to the site's repo on github to upload the files and add an entry to a dropdown, but thats not a huge deal. I could also dynamically load dropdown entries and recent entries on the homepage, but cannot be bothered at the moment.

This is kinda weird, but expect a more normal Blog-like post soon. I just wanted this set up now so I could add more without needing to do the setup and writing at the same time.
